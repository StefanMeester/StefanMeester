# Portfolio: set up in 10 minutes
1. Make a free account on github.com. Create a **public** repository named exactly `YOURUSERNAME.github.io` (this matters: the 404 page and links expect the site at the root).
2. Open the repo, choose **Add file > Upload files**, drag in everything from this folder (index.html, the css, js and img folders...), then **Commit changes**.
3. Go to **Settings > Pages**. Under "Build and deployment" pick **Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
4. After about a minute your site is live at https://YOURUSERNAME.github.io
5. Edit `js/content.js` (name, email, videos, photos) and the text in about.html / contact.html (click the pencil icon on GitHub). Your name, email, Instagram and LinkedIn are all set in js/content.js. See the PDF guide for everything else.
6. Photos: save as WebP or JPG (max 1800px wide) in the `img` folder. Put a portrait at `img/me.jpg`.

# Adding a project
Open `js/content.js`, copy one project block, paste it at the top of the list and change the values (the explanation is in the file). Upload the thumbnail or photos to the `img` folder. The Projects page, the filters and the "Latest projects" on the homepage update by themselves, newest date first.
